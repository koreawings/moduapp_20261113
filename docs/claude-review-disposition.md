# Claude 코드 검토 반영 기록

실제 Claude Code에 서버·계약·테스트 소스를 제공한 정적 교차 검토 결과는 [원문](claude-code-review.md)에 보존했습니다. Claude는 코드를 실행하거나 브라우저를 시험하지 않았습니다. 제안과 실제 반영·검증을 분리합니다.

| 항목 | 처리 |
| --- | --- |
| 상태 변경이 기존 승인을 유지 | 상태·수집·유효기간 변경 시 초안/검토 무효화. 현재정보 출처의 미래시각 거부, reviewed≥fetched와 로컬 24h 기본상한 적용 |
| 만료된 open이 공개 API에 남음 | 공개 응답 unknown으로 정규화, last-known 보존. closed를 자동 개방으로 바꾸지 않음 |
| 번역 승인 플래그만 존재 | en/zh-TW 실제 title/summary/startPoint, 원문·번역 fingerprint, 변경 후 별도 승인, 누락/불일치 제외 |
| 독립 승인자 정책 | 로컬 단일 운영자 자기검토 허용은 감사 기록에 명시. 이것을 독립 인간 언어검수 완료로 부르지 않음. 공개운영 승인정책은 후속 결정 |
| 감사·코스 버전 불변성 | migration2에서 DB UPDATE/DELETE 방지 trigger, v1 신고 보존 시험 |
| 공개 reviewer 로그인ID·계정 전체 잠금 | 공개 reviewer null, reviewed boolean. 로그인 시도 IP+username으로 구분 |
| 동시 migration | writer transaction 안 버전 재확인. 통합시험에서 WAL전환 경합도 발견해 추가 수정·회귀 수행 |
| 잠긴 방에서 기존 메시지 ACK 재시도 | 현재 권한과 기존 메시지 확인 후 동일 멱등 응답, 새 입력만 잠금 차단 |
| 댓글 신고/오래된100개 고정 | comment 신고·숨김·복구, 최신100개를 시간순 표시. 이전댓글 pagination은 미구현 |
| 광범위 추가정책 | 댓글 평생 작성상한, 무조건 별도 승인자, 불필요한 사용자 재승인 절차는 이번 범위에 자동 도입하지 않음 |

원저자 외 에이전트가 프론트 방/계정 전환 경합, 역할회수 화면 초기화, 원본 ISO 보존, 만료상태 표시, URL 자격증명 금지, 미래 증거 날짜를 검토했습니다. root는 실제 브라우저와 전체 실행기로 통합 확인합니다. 최종 원본 통과 로그와 입력 지문은 reports/turnkey/ledger.json이며, 실패 실행도 지우지 않습니다.

현재 솔루션은 로컬 단일 프로세스 HTTP/SQLite입니다. 호스팅·다중 인스턴스·백업복구·실기기·독립 언어검수·현장 코스·고객지불가치를 이 코드검토로 보증하지 않습니다.
